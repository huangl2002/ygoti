# YGOTI · 游戏王卡组人格测试

> **Y**u-**G**i-**O**h **T**ype **I**ndicator — 用决斗者的人格找到你的本命卡组。

一个纯前端的人格测试小应用，通过 24 道题测量你在四个维度上的倾向，匹配 16 种决斗者人格类型，推荐最适合你的游戏王卡组。

## 特性

- **24题四维测评** — 展开/应对(CR)、强攻/防守(AD)、魂系/竞技(SM)、速攻/持久(QG)，每维3正3负平衡设计
- **16种人格类型** — 从"魂之OTK"到"深渊掌控"，每种匹配专属卡组推荐
- **24套卡组数据库** — 含历史地位、梗、玩法标签（珠泪、闪刀、烙印、虫惑魔、青眼…）
- **决斗者评语系统** — 64条满载游戏王梗的趣味评语（30-40字），每次结果随机抽取
- **一致性检测** — 同维度答案标准差校验，标注可信度（★/☆/◎）
- **分享图片生成** — Canvas 绘制决斗者档案卡片，一键保存 PNG

## 技术栈

纯静态页面，零依赖，浏览器直接打开 `index.html` 即可运行。

## 本地运行

```bash
# 任意方式启动静态服务
npx serve .
# 或
python -m http.server 8080
```

然后浏览器打开 `http://localhost:8080`。

也可以直接双击 `index.html` 打开（分享图片保存功能需 HTTP 服务）。

## 项目结构

```
ygoti/
├── index.html      # 主应用（HTML + CSS + JS）
├── test_ygoti.js   # Node.js 自测脚本（模拟30次答题统计分布）
├── decks/          # 24张卡组封面图（PNG）
├── CHANGELOG.md    # 更新日志
└── README.md
```

## 自测

```bash
node test_ygoti.js
```

模拟3种答题策略（随机/极端/中立）各10次，输出类型分布、维度倾向、边界统计等报告。
